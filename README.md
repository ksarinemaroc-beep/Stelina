# Stelina

Thème Shopify de la marque Stelina, basé sur Dawn 16.1.1 (Online Store 2.0).

- Thème : `assets/`, `config/`, `layout/`, `locales/`, `sections/`, `snippets/`, `templates/`
- Catalogue à importer : `catalogue/products.csv`
- Photos à envoyer dans Shopify : `photos/`
- Guide et modèles de pages légales : `docs/`

Les ajouts propres à Stelina portent le préfixe `stelina-` (sections, snippets, `assets/stelina.css`, `assets/stelina.js`).
